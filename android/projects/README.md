# Android Projects

Put Android Gradle projects in this directory, or symlink existing project folders here.

Example:

```bash
ln -s /home/nybo/my-app /home/nybo/android-projects/my-app
```

The web GUI at `/android-dev.php` lists entries that contain `gradlew`, `settings.gradle`, `settings.gradle.kts`, `build.gradle`, or `build.gradle.kts`.
